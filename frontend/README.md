# Crisis Messaging — Frontend

Next.js frontend demonstrating the crisis messaging backend, providing a conversation view between a therapist and a patient.

## Getting Started

Install dependencies and run the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the app.

## Project Structure

- `app/` — Next.js App Router pages and layout
- `components/` — conversation UI components (`ConversationView`, `MessageList`, `MessageForm`)
- `src/lib/api.ts` — backend API client
